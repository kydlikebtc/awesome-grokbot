# Code of Conduct

## The short version

This is a link catalog. Contributions are judged on whether they are accurate, attributed, and in scope — nothing else about the person sending them.

## Expected behaviour

- Be accurate over enthusiastic. If you have not opened the link, say so.
- Credit people. Every row must name where it came from; that is a rule about respect as much as about licensing.
- Assume the other person is trying to help. Most catalog disagreements are stale data, not bad faith.
- Accept correction gracefully. Everyone here is transcribing someone else's work; mistakes are routine.

## Unacceptable behaviour

- Harassment, insults, or personal attacks, including about someone's English or Chinese.
- Publishing anyone's private information.
- Adding a bot with a description you know to be misleading, or listing a bot in order to harm someone.
- Using issues or PRs primarily to promote something unrelated.

## Scope

This applies to issues, pull requests, discussions, and any other space representing this project.

## Enforcement

Report a problem by [opening an issue](https://github.com/kydlikebtc/awesome-grokbot/issues/new). If it involves someone's private information or you would rather not report publicly, use GitHub's [private reporting](https://github.com/kydlikebtc/awesome-grokbot/security/advisories/new) instead.

Responses escalate as needed: a correction, a warning, removal of a contribution, or a block. Maintainers who do not follow this document should be held to it too.
